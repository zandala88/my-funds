# My Funds · 基金自选

个人使用的轻量原生安卓基金工具。持仓、分组、操作记录和设置保存在手机；联网只查询行情及基金资料，换机使用文件备份。

## 已确定的方向

- Kotlin + Android 原生 View/Canvas + SQLite，Android 8.0 及以上。
- 不需要账号、服务器、域名、付费数据源或推送服务。
- 导出单个 JSON 文件，在新设备导入恢复；导入前校验，保留本机恢复点。
- 基金搜索、自选、持仓收益、交易记录、分组、走势图和基金资料。
- 盘中估值取决于数据源是否返回有效数据；缺失时明确标记，不能当成零涨跌。

设计与实施计划见 [设计](docs/superpowers/specs/2026-11-24-funds-native-android-design.md) 和 [计划](docs/superpowers/plans/2026-11-24-native-android.md)。

## 使用

在安卓手机安装正式签名 APK。进入“自选 → 添加”，输入名称或基金代码搜索；添加后录入已确认份额和平均单位成本。长按基金可编辑持仓、记录加减仓、校准份额、关注、移动分组或调整顺序。点击基金查看净值走势、资料、经理、披露持仓及最近操作记录。

“行情”中手动刷新指数，可选择指数、查看指数走势与行业板块主力资金。“设置”中调整外观、显示项和前台自动刷新。自动刷新默认关闭，退到后台或锁屏时停止；没有账号登录或后台推送。

### 换手机

1. 旧手机进入“设置 → 导出完整备份”，选择一个文件保存位置。
2. 通过你自己的方式把 JSON 文件传到新手机，并安装 My Funds。
3. 新手机进入“设置 → 导入备份 / 换机恢复”，选文件，核对数量后确认。

导入会替换本机数据；导入前自动保存一个本机恢复点，可在“设置 → 恢复至上次导入前”撤回。文件损坏、超过 8MB、版本不兼容或记录无效时拒绝导入，保留原数据。重复导入不会增加重复交易。备份为明文，包含持仓信息，保存位置由你选择；图表和行情缓存重新联网获取。

### 收益口径

- 持有金额及持有收益按已公布净值计算。没有对应净值时显示暂无，不当成零。
- 加仓费用计入平均成本；减仓费用从卖出收入扣除，剩余持仓平均成本保持不变。
- 已实现收益仅覆盖建账后记录的卖出；初始持仓是快照，不推算快照前盈亏。分红、份额折算用校准功能手动记录。
- 当日收益按期初份额计算，今天买入的份额不凭空获得之前的涨幅，今天已清仓的基金仍计入当天收益。初始份额或当天校准无法还原期初时显示未知。首次录入请填写这份持仓已确认的日期。
- 当日已公布收益按公布的涨幅反推上一净值，受涨幅精度影响，可能与销售平台对账有小额差异。估算收益单独标记；同日正式净值公布后优先显示正式数据。操作需按确认日期依次录入，拒绝倒序和未来确认日。
- 历史收益曲线是基金区间涨幅，与个人账户按交易计算的收益不同。

## 构建

要求 JDK 17、Android SDK Platform 35、Build Tools 34.0.0。可用 Android Studio 打开仓库，或用命令行设置 `JAVA_HOME` 与 `ANDROID_HOME` 后执行：

```sh
./gradlew :core:test :app:assembleDebug :app:lintDebug
```

本次开发环境也可运行 `scripts/build-local.sh`，它优先使用本机缓存中的兼容 Gradle/JDK。Gradle Wrapper 固定 8.9，依赖来自 Google Maven/Maven Central。

正式版使用你自己的持久签名密钥：

```sh
python3 scripts/create-signing-key.py
scripts/build-local.sh :app:assembleRelease
```

APK 输出为 `app/build/outputs/apk/release/app-release.apk`。没有配置正式密钥时会生成 unsigned 包，不要把它当成可安装的正式包。密钥和密码位于 `~/.local/share/my-funds/`，不在仓库和持仓备份中；请另外保管这两个文件，后续更新需要保持签名一致。

## 验证与限制

见 [验证记录](docs/verification.md)。核心回归测试覆盖金额精度、手续费、超额卖出、备份往返与破损文件、业务报错、缺失估值和数据时间。

SQLite 持久化、重复导入及恢复点的 instrumentation 测试已编写。连接开发用安卓设备后可运行：

```sh
scripts/build-local.sh :app:connectedDebugAndroidTest
```

应用只申请 INTERNET 权限，导入导出走系统文件选择器；关闭 Android 自动云备份与设备自动提取。缓存可能过期，请看每只基金的净值日期和指数时间。已获取的走势和基金资料可离线回看；大列表分成每页 50 只展示以限制页面内存。行情接口没有本项目可提供的可用性承诺；接口不可用时仍能使用本机数据和文件备份。
