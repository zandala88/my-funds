# 拾盈 · My Funds

个人使用的轻量原生安卓基金工具。持仓、操作记录和设置保存在手机，联网用于查询基金行情、名称等公开资料，换机通过文件备份完成。

当前源码版本 **0.8.0**（已发布下载包仍为 0.7.0），支持 **Android 8.0 及以上**。无需账号、自建服务器、域名或推送服务。

## 功能

- 按基金名称或六位代码搜索，管理自选、持仓、关注、分组和排序；首页可直接进入编辑模式，手柄拖动自适应快慢，上移 / 下移平滑无闪烁，多选后批量删除。
- 记录份额、平均成本、加减仓及持仓校准，按行情日期查看单日收益、第三方盘中估值、各类型本机模型/收益预测、累计持有收益和本机操作流水。
- 支付宝持仓截图本机离线 OCR，支持多图识别、QDII 自动纠错、长屏切片扫描、结果核对与一键全选。
- 每日定投按固定金额设置，系统每日自动根据净值折算份额、累计更新持仓与成本，显示单日预计投入合计。
- 浅深色外观、“红涨绿跌 / 绿涨红跌”，以及“较小 / 标准 / 较大”三档字体和界面尺寸；配色和字号选项提供实际样式预览，设置随备份保存。
- 导出与导入 JSON 备份，导入前保留一个本机恢复点。

## 使用

**界面与定投：** 右上角设置图标打开设置，返回箭头回到自选；底部无固定导航栏。在“字体与界面大小”中调整文字、间距和控件尺寸，窄屏或大字号会自动调整排列。点击首页“每日定投预计”查看卡片式计划列表，展示基金、执行规则、每日定投金额及单日预计投入；通过“编辑计划”调整对应基金。

**添加持仓：** 在“自选”中搜索并添加基金，录入已确认份额、平均单位成本和结算日期。卡片右上角实时同步结算日期。点击基金查看详情，长按管理持仓与定投。

**编辑自选：** 点击首页基金列表旁的“编辑”，长按右侧手柄拖动（边缘感应动态快慢调节），或用“上移 / 下移”在原位无闪烁调整顺序。更改即时保存在本机；点击“完成”或返回键退出。编辑当前分组时只调整该组，关注标记保留且不会覆盖自定义顺序。可跨页勾选或全选当前列表，点击删除并确认后，移除已选基金及其操作记录、定投计划，未选基金保留。

**截图导入：** 点击“截图导入”，从照片选择器或相册选择截图。单次最多 12 张、50 条核对结果；逐张识别后统一核对，可一键全选。同一基金的相同快照会合并来源，数值冲突时需选择保留哪条。旧系统相册的多选能力取决于手机厂商实现。

OCR 不会把待确认金额当作已确认持仓，也不会按金额反推份额和成本。请核对基金代码、A/C 类别、数值及结算日期，遗漏或不确定的字段可以补齐，也可以只加入自选。图片在本机处理，不上传、不写入持仓备份；识别后仅按基金代码联网核对公开名称。

**换机备份：** 旧手机在“设置 → 导出完整备份”保存 JSON 文件，传到新手机后，通过“导入备份 / 换机恢复”导入。导入会替换本机数据，可通过“恢复至上次导入前”撤回。备份是明文文件，包含持仓信息，请自行保管；签名密钥与行情缓存不在持仓备份中。

## 数据与计算

- 行情和基金资料来自东方财富 / 天天基金公开接口，无需在应用中配置接口密钥。接口可能变化或暂时不可用，应用不提供数据服务保障；无有效净值时，相应收益或预算显示未知。
- 单日收益按行情日期标注：当天公布净值显示“今日收益”，当天盘中估值显示“今日估算”；旧净值显示“昨日收益”或具体日期，列表和详情标明净值日期或估值时间。首页仅汇总当天数据，缺失时标明覆盖数量，不混入历史收益；零涨跌估值也作为有效的当天估算。
- 本机估算覆盖股票、指数、混合、债券、可转债、固定/浮动净值货币、QDII、FOF、黄金/商品，以及场内 ETF/REIT；场外基金正式净值优先于第三方估值，第三方估值优先于模型；场内 ETF/REIT 则采用成交价相对昨收的日盈亏，公布净值保留为独立记账口径。未知类型仍可用第三方数据，模型缺少必要资料时明确显示原因。
- 股票/混合按披露权重计算重仓贡献，剩余已知股票仓位使用指数代理；债券使用期限/信用类别对应的债券 ETF 或转债指数代理，保留披露的杠杆。ETF 联接/商品可能使用目标 ETF 价格作为代理，包含折溢价变化，不等于 IOPV。调仓、费用、融资成本及代理误差不能据公开数据精确还原。
- 货币基金的接口 `NAV` 可能是万份收益，应用将其与单位价格分离：固定净值货币价格按 1 记账，当日已公布万份收益按每一万份计算；未公布时按最近 7 天内的万份收益/七日年化作单日收益预测，浮动净值货币保留真实单位净值。
- 海外行情使用来源市场日期，并按同一参考日区间复合汇率收益；人民币价格代理不会重复叠加汇率。昨夜海外收盘只属于对应海外交易日，不混入北京时间今日合计；日线资产与汇率收盘时点仍存在近似。无法核实海外交易日的第三方估值，以及跨越多个工作日的估值净值差，不作为今日收益；降级到区间明确的模型或显示未知。支持美元、港币及可取得汇率的其他币种，外币收益单独列示，持仓概览的人民币合计不直接相加外币金额。
- FOF 最多穿透 4 层、每轮最多获取 256 只额外子基金，检测循环；子基金缺少匹配日期区间及币种换算的完整收益或未披露其余配置时，仅显示部分贡献。对无法匹配的跨市场比较区间、超过 200 天的披露、未知资产及缺失行情，不补零或将前十大权重放大至 100%。页面区分直接行情覆盖与模型覆盖，并列明模型来源、披露日、行情时点、可信度和具体假设。部分贡献不计入完整今日合计。
- 基金元资料通常缓存 24 小时，不完整资料 5 分钟后重试；股票行情批量去重，元资料获取最多 4 路并发，元资料失败保留已知币种。主净值接口失败也继续尝试模型/场内行情；没有正式净值的 ETF/REIT 可以独立保存场内收益。先保存公布行情，再补充模型，单源或单只基金失败不会覆盖已获取的正式净值。
- 截图识别使用内置 Tesseract 中文模型，不依赖云 OCR 或 Google 服务，识别结果需核对后才会写入持仓。
- 定投是**本机记账与预算功能**，不会向支付宝或基金公司发起买入。按周一至周五执行的选项不识别节假日。
- 定投按每日金额统一计算预算与折算份额，根据当日公布净值自动累计增加份额并加权更新持仓成本；缺少净值时采用回退持仓成本估算。它不是逐日银行实际扣款。
- 应用仅申请网络权限，关闭 Android 自动云备份。前台自动刷新默认关闭，开启后每 60 秒请求一次，退到后台即停止；刷新成功不代表行情已更新至今天。

## 构建

使用 Kotlin、Android 原生 View/Canvas 和 SQLite。需要 **JDK 17、Android SDK Platform 35、Build Tools 34.0.0**，Gradle Wrapper 固定为 8.9。

配置 `JAVA_HOME` 和 `ANDROID_HOME` 后执行：

```sh
./gradlew :app:assembleDebug
```

正式版需先创建并保留个人签名密钥：

```sh
python3 scripts/create-signing-key.py
./gradlew :app:assembleRelease
```

签名文件保存在 `~/.local/share/my-funds/`，不进入仓库。后续覆盖安装需使用同一签名，请单独备份密钥及其配置。未配置密钥时生成的 release 包未签名。

APK 位于 `app/build/outputs/apk/`：较新的 ARM64 手机使用 `app-arm64-v8a-release.apk`，其他架构可使用 `app-universal-release.apk`。本项目另提供 `scripts/build-local.sh`，可在已有本机工具缓存的开发环境代替 `./gradlew`。

依赖来自 Google Maven、Maven Central 和 JitPack。OCR 引擎与模型许可随应用打包，可在“设置 → 开源许可与识别模型”查看。

## 检查

```sh
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug
```

核心测试覆盖持仓计算、备份、OCR 解析和定投预算；Robolectric 检查 Android 9 / 15 下的弹窗布局、定投列表、全选、字号及配色设置。真实手机上的相册、输入法、厂商界面及原生 OCR 仍需实机确认。

连接开发设备后，可编译并运行设备检查：

```sh
./gradlew :app:connectedDebugAndroidTest
```
