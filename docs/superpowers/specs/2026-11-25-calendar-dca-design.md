# 收益日历与定投计划升级

用户选择实现上轮建议的收益日历和定投计划升级。沿用原生 Android/Kotlin、本机 SQLite 和现有行情源，继续测试、Git 推送与同签名 ADB 覆盖安装流程。无需服务器或账号；定投始终是本机计划记账，不向基金公司/银行提交买入。

## 收益日历

- 首页新增明确入口，提供月历、上/下月、本月、日/周/月统计与选日基金明细，跟随涨跌配色、字号和深浅外观。
- 按收益所属日期和币种保存快照，区分公布净值计算、估算、部分贡献和待补数据；正式数据可替换同日估算，估算不能覆盖已公布结果。外币单独统计，缺数据不记成零。
- 已有历史通过每日净值接口和可信的持仓基准/操作记录补算，从基准日次日起计算；无初始份额或当日校准时保留未知。日初份额通过初始份额及此前 BUY/SELL/DCA/CALIBRATE 事件重放；当日新买入/定投份额不追溯赚取此前涨幅，当日交易费扣减。
- 历史净值接口使用完整日期范围，保留前一日净值、公布涨幅、万份收益和分红/拆分标记。货币万份收益不能作为价格；不明分红/拆分影响且无可靠涨幅时保留未知。模型和海外收益不改日期冒充今日。
- 月/周统计只将有依据的已公布金额列入已公布合计，估算和部分覆盖分列并注明覆盖数量；月历空白不是零收益。快照含当时基金名称、代码和分组，可在移除持仓后保留历史。历史持仓基准之前不反造收益。
- 新记录进入完整备份，旧 schema 1 备份可导入，新格式 schema 2；财务列表及字符串均有边界检查，备份容量调整至 32MB 以容纳日历数据。

## 定投计划

- 支持每交易日、每日（自然日）、每周指定星期、每月指定日；月份没有指定日时取月末。支持生效/结束日期、暂停/恢复、跳过本次及历史执行记录。
- 每交易日只在确认开市日生成一次。周/月计划可选休市顺延、休市跳过或按计划日；同一计划周期使用稳定执行 ID，不因刷新/重启/导入重复记账。不同周期顺延到同一天仍是不同期次。
- 使用交易所年度日历，周末调休上班不当作开市。内置已核实的 2026 休市日期，并从上交所年度休市页更新；未确认年份为待日历状态，不猜测交易日。QDII/特殊估值日没有正式净值则等待，不用预测或成本价格充数。
- 只有执行日期相符的正式净值才能折算份额；缺净值保存待净值记录，后续从每日净值历史补齐。已有更晚操作时不能倒插改变成本/已实现收益，转为待核对，支持跳过。
- 计划保存配置修订后，从本次生效日生成新周期，取消未记账的旧修订；暂停期间不补执行，暂停前待净值记录保留。已记账流水不重算。当天已记过定投时，修改计划不自动再记一笔。
- 旧金额/份额定投及流水保留，旧配置按原每日/工作日意图衔接；新建/编辑只提供金额输入。旧的成本回退计价不追溯伪装成正式净值。
- 预算显示今日计划、下次日期、暂停/待净值/待核对状态与累计已记投入，按币种分列；实际记账日期与计划日期分开，明确并非银行扣款。

## 数据与实现

core 增加 TradingCalendar、DailyNav/历史解析、IncomeCalendar（时间线/快照/统计）、DcaSchedule/DcaExecution/DcaEngine；Portfolio 和 BackupCodec 向后兼容扩展。Android 增加独立日历与计划编辑视图，网络获取月度净值与年度日历后基于最新 Portfolio 合并，防止后台结果覆盖用户编辑。已有记录全部保留，清理行情缓存不清理收益日历。
